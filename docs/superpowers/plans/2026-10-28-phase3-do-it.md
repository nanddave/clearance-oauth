# Phase 3: Do It / Prepare It Implementation Plan

> Executed inline, audited before phase 4.

**Goal:** The guide tracks where the developer is, and for each step either does it (pre-filled provider page), prepares it (copy-ready text or script), or says only you can.

**Architecture:** A `done` set joins the URL selection; the engine skips done gates, so the next-action card, clocks and order follow progress. Kits (`src/lib/kits.ts`) are pure functions from (guide, gate) to links, forms or copy blocks, with no model calls; the PRD's Drafter becomes templates, which are cheaper and never hallucinate. The error decoder (`src/lib/errors.ts`) is a pattern table, also with no model.

**Spec:** `docs/superpowers/specs/2026-10-28-clearance-prd.md` §4–§6, P3.

## Global Constraints
- No secret ever reaches our server. GitHub's manifest flow returns a `code` to our page; we never exchange it. The setup kit runs on the developer's machine.
- Composio redirect URI: `https://backend.composio.dev/api/v3/toolkits/auth/callback` [O, docs.composio.dev programmatic auth configs, 2026-10-28].
- Composio SDK: `@composio/core`; `authConfigs.create(toolkit, { type: "use_custom_auth", authScheme: "OAUTH2", credentials })`, `connectedAccounts.link(userId, authConfigId)` → `redirectUrl`, `waitForConnection(ms)`.
- Slack pre-fill: `https://api.slack.com/apps?new_app=1&manifest_json=<urlencoded>` [O].
- GitHub manifest: form POST to `https://github.com/settings/apps/new` with `manifest` [O].
- Error patterns carry where they come from; nothing is labelled official unless a provider page says it.

## Review Focus
1. A done gate that others depend on: dependants must still schedule (done gate counts as zero time).
2. Every gate done: no next action; the card says you're live and waiting on nothing.
3. Unknown ids in `done=` from a shared URL are ignored.
4. Error text that matches nothing → "not recognised" with the generic checks, never a guess.
5. App name with quotes or emoji in manifests → JSON-encoded and URL-encoded correctly.

## Tasks
1. **Done gates in the engine** (`Selection.done`, `parseSelection`, `toSearchParams`), with tests.
2. **Kits** (`kits.ts`): Slack manifest link, GitHub manifest form, Composio setup script, Gmail Limited Use and scope justification, Gusto pre-approval email; tests for encoding.
3. **Error decoder** (`errors.ts` + section), with tests.
4. **UI:** stage tracker, "Mark done" on the next-action card, kits on the card and in the path list; Slack and GitHub `create_app` → `agentCan: "do"`.
5. **Verify:** tests, build, lint, a browser pass.
